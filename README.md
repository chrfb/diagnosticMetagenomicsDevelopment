This tool is a development version of a clinical diagnostic metagenomics pipeline using Illumina 
and Nanopore sequencing on sterile biological materials (for clinical use in infectious disease management). 

Affiliation: Oslo University Hospital, Department of Microbiology

This repository is currently a dummy repository created to allow NCBI to raise
issues on this repository in case the tool interacts in an inappropriate way with the API,
although all efforts will be made to respect NCBI API policy. Source code may be uploaded
at a later time when the project matures.

For NCBI system administrators: Please do not hesitate to give feedback in case of any issue.

Currently in alpha testing.

Phase 1: Establish NCBI Datasets API interaction for downloading taxonomy data.
